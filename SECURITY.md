# Security

Report vulnerabilities to security@wellworn.dev. Include the endpoint or file, reproduction steps, and impact. You will get a reply within three working days and a fix timeline within seven.

Scope: the MCP server and packages in this repository, the hosted endpoint https://mcp.wellworn.dev, the plugin and skills. Out of scope: third-party registries and sites the importers read.

Please do not run load tests against the hosted endpoint; the public tier is rate limited and abuse is blocked at the edge.
